# Benson Eastern Oregon Partner Pack

This Benson edition partner pack extends the upstream `us-rsmeans` profile for
Benson Home Solutions. It fixes the tenant defaults to USD, imperial units,
English (`en-US`), and Oregon while requiring each project to provide its own
county, local jurisdiction, and IANA timezone.

The pack deliberately contains no county allowlist and does not assume a
single timezone for Eastern Oregon projects.
